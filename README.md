ТРЕБОВАНИЯ К СИСТЕМЕ
--------------------
• ОС: Microsoft Windows 10 / 11 (x64)
• .NET Framework: 4.7.2 или новее
• СУБД: Microsoft SQL Server 2017+ или SQL Server LocalDB
• ОЗУ: не менее 4 ГБ
• Свободное место на диске: 500 МБ

ПОРЯДОК ПЕРВОГО ЗАПУСКА
-----------------------
1. Установите SQL Server LocalDB (входит в состав
   SQL Server Express) или полноценный SQL Server.

2. Откройте SQL Server Management Studio (SSMS) и
   подключитесь к серверу.

3. Откройте файл database\database_script.sql из
   каталога установки и выполните его (F5).
   Скрипт создаёт базу KosmicheskayaLozha и заполняет
   её тестовыми данными.

4. При необходимости откройте файл
   KosmicheskayaLozha.exe.config в любом текстовом
   редакторе и в секции <connectionStrings> укажите
   корректное имя SQL-сервера (data source).
   По умолчанию используется (localdb)\MSSQLLocalDB.

5. Запустите программу через ярлык «Космическая ложа»
   в меню «Пуск» или на рабочем столе.

ВЫЗОВ СПРАВКИ
-------------
В работающей программе нажмите клавишу F1 для вызова
встроенной справочной системы.

ДЕИНСТАЛЛЯЦИЯ
-------------
«Параметры» → «Приложения» → «Установленные приложения» →
«Космическая ложа» → «Удалить»,
либо запуском unins000.exe из каталога установки.
